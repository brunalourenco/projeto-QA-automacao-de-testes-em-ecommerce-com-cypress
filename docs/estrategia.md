# Estratégia de testes

## Tipos de testes realizados

Não foi localizada documentação da aplicação por isso os testes foram iniciados com testes exploratório para entendimento do fluxo e identificação de cenários.

- Teste exploratório
- Teste funcional
- Teste manual
- Testes automatizados com Cypress
- Testes E2E
- Validação de campos
- Testes positivos e negativos
- Teste BVA (Valores limite) nos campos de quantidade de itens no carrinho e caracters no cep.

## Técnicas de testes

-Utilizei técnicas caixa preta, que não consideram o código fonte. Foram realizados testes manuais e exploratóros para conhecer os fluxos e testes automatizados para facilitar, otimizar tempo e recursos na realização de novos testes caso sejam realizados ajustes e alterações em funcionalidades sistema que apresentaram bugs.

- Análise de valor limite - aplicada nos campos de nome e senha, com o objetivo de verificar o comportamento do sistema em relação aos limites mínimos e máximos de caracteres permitidos em cada campo.

## Critérios de aceite

Os testes foram considerados satisfatórios quando:

- O sistema apresentou o comportamento esperado
- As validações funcionaram corretamente
- As mensagens de erro foram exibidas adequadamente
- As funcionalidades foram realizadas com sucesso nos cenários válidos.
